# Archived Documentation

This directory stores frozen references, historical reports, and sprint artifacts that are no longer part of the active delivery workflow but remain valuable for context.

## Structure

- `Phase_2/` — Phase 2 playbooks, checklists, and validation results.
- `Phase_3_Sprints/` — Sprint-level plans and retros for Phase 3.
- `reports/` — Executive reviews, blocker write-ups, migration notes, and security audits.

## When to Archive

Move a document here when its guidance no longer represents the live state of the platform (e.g., sprint completed, blocker resolved, migration executed). Keep filenames timestamped or phase-scoped to preserve chronology.

## Access Patterns

- Start with the most recent report in `reports/` for historical decisions.
- Reference phase folders when revisiting legacy implementation details or postmortems.

## Maintenance

- Periodically prune redundant copies if newer summaries supersede older ones.
- Link back to relevant archive entries from active docs when they provide background.
